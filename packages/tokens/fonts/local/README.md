# Font locali

Questa cartella contiene i font che non si possono pubblicare nel repository. Git ignora tutto tranne questo file.

- `MFOddMono-Regular.woff2` (oppure `.woff`): MF Odd Mono di [Metis Foundry](https://metis-foundry.com/oddmono/), font dei titoli dei siti attuali. È commerciale: la licenza è di chi l'ha acquistata e non permette di pubblicarne i file. Mettilo qui solo se hai una licenza valida.

Senza il file, `--font-display` ripiega sul font alternativo scelto (vedi `src/fonts.css`).
